# P3-A3 post-task shadow design

Default `EXPERIENCE_MEMORY_MODE=off`; only explicit `shadow` is accepted. `active` fails settings validation. Configuration lives in the new ExperienceSettings class; all pre-existing production files remain unchanged. No business service, Graph node, Context Builder, Memory M2, Planner, Retriever, Generate or Judge imports the new package. There is no online hook to queue, await or inject experience. Use an explicit offline runner after completed traces have been saved.

The pipeline consumes trusted offline structural assessments, not arbitrary user prose. EvidenceResolver enforces relative in-root JSON paths, file-size bounds, exact SHA256 and resolvable JSON pointers. Scope uses opaque tenant/user/session references and a trusted offline verification assertion, not public ChatRequest identity. These assertions are not a newly implemented production authenticator. Root-cause hypotheses remain distinct from verified failure.

Reflection is a bounded deterministic catalog of three generic candidate principles, derived from audited mixed-evidence routing, Judge structured errors and fallback evidence failures. It is not an LLM inventing unbounded rules, nor proof of learning. Each requires qualifying verified failure and independently annotated source-context prerequisites. Unsupported categories, likely/unknown failures and evaluator artifacts return NO_SAFE_LESSON. Raw trace text, tool text, personal records and reasoning are not copied into lessons or hypotheses. Exact reviewed catalog text/conditions are validated at every candidate ingress; free-text injections, secrets, phone/email/order-specific lessons are rejected rather than merely masked. Full source evidence remains external, private and hash-referenced.

Candidate schema includes scoped provenance, failure class/confidence, evidence refs, explicitly hypothetical root, generic lesson, positive/negative applicability conditions, low risk, separate validation/review statuses, version and bounded UTC creation/update/expiry. Initially PROPOSED/UNREVIEWED. No code creates ACTIVE. Proposed source examples and applicability labels never enter the business Agent.

ShadowObserver never passes the completed business result to reflection or a persistence callback. It checks completion and explicit mode, bounds observations to64(default, hardmaximum256), prevents duplicate trace processing within scope/version and isolates ordinary parser/reflection/DB callback exceptions to a content-free ERROR outcome. Failed attempts are not endlessly retried. Observer/task cancellation is not a business retry mechanism; this offline process owns no business transaction. The later repository uses independent sessions/transactions.

RED19missing-feature failures, plus a separate source-context prerequisite RED, then34focused tests pass. Off mode performs no evidence or sink access. Tests cover injected candidate text, invalidscope, expiry, relative/hash/pointer checks, original-result immutability, completion, duplicate/rate bounds and sink failure. Initial lint and Mypy catalog-inference errors were corrected with formatting and explicit TypedDict/Literal types. Full-suite evidence is recorded separately.

`a3_context_assessments.json` is a new normalization version with source task tags; the earlier A2 normalization is preserved. Tags are reviewed structural annotations from the reflection-development corpus, not autonomous language understanding. Independent applicability data were authored without implementation/result access and remain unread until implementation freeze. The A2 adapter validates140primary reference uses; the independent evidence review also checks15secondary references (155total), as distinguished from27unique sources. No blind accuracy is claimed for reproducing20reviewed labels from their supplied signals.

No new paid requests. Future persistence initialization is explicit and isolated. Disable mode/remove the offline runner to roll back observation; existing business behavior needs no rollback because it was not wired to experience.
