## 设计与边界

唯一符合本轮约束的路径是沿用已有 React / FastAPI / LangGraph / 私有 RAG / Docker 生命周期。Offline 保持确定性与网络门禁；Real Dev 增加独立显式入口和有限持久预算。前端不管理模型凭证或付费权限，不保留 Experience 实验展示。另建 Agent 或让前端切换付费模式会重复或绕过既有机制，因此不采用。

当前真实问题是私有政策资料为空叠加 Offline 能力有限，不是 HTTP 失败或检索异常。不得将公共政策无授权注入其他用户私有库，不得把离线提示 JSON 当自然语言答案。使用独立合成验证环境验证三个业务场景，保留现有工作台数据库状态。

Real Dev 要求服务端显式启用、有效 Key、持久预算文件和有限的请求次数/Token/费用上限。每次 HTTP 尝试先原子预留（包括重试和流式），重启不清零；传输结果不确定时保留预留并拒绝静默重放。预算账本不保存问题、回答或密钥。保留原上下文 Token 上限。测试只用假 Key + MockTransport/拒绝网络，Real Dev 不实际启动付费请求。
